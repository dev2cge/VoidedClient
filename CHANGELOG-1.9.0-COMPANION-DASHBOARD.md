# VoidedClient 1.9.0 — Companion Dashboard

- Adds a configurable **U** keybind for the unified Voided Network dashboard.
- Adds server-authoritative balance, playtime and RPG-level leaderboards with ten entries per page.
- Adds Minecraft and Discord linked-account status, short-lived link-code requests and unlink controls without exposing credentials.
- Adds an interactive server browser with validated network transfers.
- Keeps J for RPG stats and K for Exploration while exposing both inside the new dashboard.
- Adds matching Fabric and Forge screens and retains the Forge serverbound packet-direction fix.
- Expands only the bounded server-to-client payload limit to 4096 bytes; client action requests remain small and server validated.
