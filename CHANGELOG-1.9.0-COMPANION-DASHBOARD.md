# VoidedClient 1.9.0 — Wave 4A Companion Complete

- Adds the configurable **U** keybind for the unified Voided Network dashboard.
- Adds server-authoritative balance, playtime and RPG-level leaderboards with ten entries per page.
- Adds Minecraft and Discord linked-account status, short-lived link-code requests and unlink controls without exposing credentials.
- Adds an interactive server browser with validated network transfers.
- Paginates the entire returned server list instead of silently showing only the first seven destinations.
- Displays network-wide online population supplied by VoidedCore 6.52.1.
- Keeps J for RPG stats and K for Exploration while exposing both inside the dashboard.
- Adds matching Fabric and Forge companion screens and retains the Forge serverbound packet-direction fix.
- Expands only the bounded server-to-client payload limit to 4096 bytes; client action requests remain server validated.
- Treats 1.8.3 as the completed pre-Wave-4A client baseline.
