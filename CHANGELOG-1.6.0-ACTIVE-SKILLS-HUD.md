# VoidedClient 1.6.0 — Active Skills & RPG HUD

- Adds configurable keybinds for all five RPG skills.
- Adds a compact in-game QoL HUD for current/max health, Strength, Defence, damage reduction, current/max mana and all skill cooldowns.
- Adds plain-language explanations when hovering an attribute name in the RPG stats screen.
- Moves the attribute rows down within the existing panel so the Attributes heading is fully visible without making the GUI taller than small screens.
- Keeps all gameplay, mana, cooldown and stat decisions server-authoritative.
