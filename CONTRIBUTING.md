# Contributing to VoidedClient

VoidedClient is source-available proprietary software. Publishing the source is intended to support security review and verifiable releases; it is not an invitation to reuse or independently modify the project.

## Bug reports and suggestions

Public issues may be used for non-sensitive bug reports and suggestions. Include the Minecraft version, loader, VoidedClient version, reproduction steps and a log with tokens, server addresses and player identifiers removed.

## Security reports

Do not open a public issue for a vulnerability or exposed credential. Use GitHub's [private security-advisory form](https://github.com/dev2cge/VoidedClient/security/advisories/new).

## Code contributions

Do not submit code changes unless a maintainer has invited the contribution and agreed separate written contribution terms with you. The repository's visibility does not grant permission to create or distribute derivative versions. See `LICENSE.md`.
