# Publish-ready VoidedClient safety copy

## Short download-page notice

VoidedClient is the optional, source-available quality-of-life companion for VoidedNetwork. It displays server-authoritative RPG information and sends only documented gameplay requests through the Minecraft server connection. It does not contain telemetry, advertising, external web requests, Discord integration, credential access, process execution, mixins or obfuscation. Players without the mod retain all vanilla fallbacks and are never kicked or restricted.

Every official release includes public source, CI build logs, SHA-256 checksums and build provenance. Verify your download using `VERIFYING-RELEASES.md` before installing it.

## Modrinth/CurseForge trust section

### Security and privacy

- Optional client-side companion; not required to join VoidedNetwork.
- No telemetry, analytics, advertising or third-party network requests.
- No access to passwords, launcher sessions, Discord tokens or browser data.
- No mixins, coremods, native hooks or bytecode transformers.
- Uses one documented Minecraft custom-payload channel capped at 512 bytes.
- Stores only Fabric HUD positions in `config/voidedclient-rpg-hud.properties`.
- Built publicly from tagged source with downloadable SHA-256 checksums.

Review the source, privacy notice, protocol specification and security policy before installing.
