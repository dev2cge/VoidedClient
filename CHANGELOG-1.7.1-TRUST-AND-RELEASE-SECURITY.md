# VoidedClient 1.7.1 - Trust and release security

- Added complete privacy, security, dependency, trust and release-verification documentation.
- Documented every additional value sent to and received from VoidedCore.
- Confirmed that the runtime has no telemetry, external web requests, credential access or process execution.
- Added deterministic JAR settings and pinned ForgeGradle instead of resolving a version range.
- Added public Fabric/Forge CI builds, SHA-256 generation and artifact publication.
- Added GitHub build-provenance attestations for tagged releases.
- Added official dependency review, Dependabot configuration and a focused source security audit.
- Gameplay, server authority and vanilla fallbacks remain unchanged from 1.7.0.
