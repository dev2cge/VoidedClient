# VoidedClient 1.10.0 — Missions Companion

- Added a native Missions tab to the Voided Network Companion.
- Added `missions-v1` capability negotiation.
- Added `missions.request` client action.
- Added `VC1|MISSIONS|...` state parsing.
- Missions display progress, target, completion state and money reward.
- The client remains presentation-only; VoidedCore owns mission progress and reward payouts.
- Public client version remains 1.10.0.
