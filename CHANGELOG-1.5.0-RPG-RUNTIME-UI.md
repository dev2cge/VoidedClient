# VoidedClient 1.5.0 — RPG Runtime UI

- Adds a live server-authoritative mana bar and regeneration value.
- Shows allocated, equipment and temporary-effect contributions for every canonical stat.
- Shows equipped RPG piece and active-effect counts.
- Displays Wave 2G hybrid build identities and their derived server-calculated bonuses.
- Advertises and parses `rpg-stats-v3` while retaining V2 and legacy packet compatibility.
