# VoidedClient 1.7.0 — Movable HUD & Skill FX

- Replaces the fixed boxed top-left RPG panel with separate health, Strength, Defence, mana and cooldown elements.
- Adds an **H** layout editor with independent persisted placement and visibility for every element.
- Defaults the elements around the vanilla hotbar to avoid the debug overlay and preserve screen space.
- Adds an enhanced central activation flash for successfully cast RPG skills.
- Sends current horizontal movement with Dash so W/A/S/D and diagonal movement determine its direction.
- Removes the incompatible direct `Options.hideGui` field access on Minecraft 26.2.
